# Встановлення та тестування — покрокова інструкція

Ця інструкція проведе тебе від «нічого немає» до «граю в ігри». Роби кроки
по черзі. Якщо щось не працює — дивись розділ **«Якщо не працює»** внизу.

Потрібен **Python 3.10 або новіший** (перевірено на 3.12).

---

## Крок 0. Перевір, чи встановлений Python

Відкрий термінал і введи:

```bash
python --version
```

Якщо бачиш щось на кшталт `Python 3.12.3` — добре, переходь до кроку 1.

Якщо пише `python: command not found` або версія нижча за 3.10:
- **Windows:** встанови з [python.org](https://www.python.org/downloads/)
  (під час встановлення обов'язково постав галочку **"Add Python to PATH"**).
- **macOS:** `brew install python` або з python.org.
- **Linux (Ubuntu):** `sudo apt install python3 python3-venv python3-pip`

> Порада: якщо `python` не працює, спробуй `python3`. На Linux/Mac це часто
> правильна команда.

---

## Крок 1. Завантаж проєкт

Якщо у тебе є git:

```bash
git clone https://github.com/Nikita-devel/python-arcade.git
cd python-arcade
```

Якщо git немає — просто розпакуй архів `python-arcade.zip`, який тобі
надіслали, і зайди в отриману папку через термінал:

```bash
cd шлях/до/python-arcade
```

> Як зайти в папку через термінал: набери `cd `, потім перетягни папку у
> вікно термінала мишкою і натисни Enter.

---

## Крок 2. Створи віртуальне середовище (рекомендовано)

Віртуальне середовище — це окрема «коробка» з бібліотеками саме для цього
проєкту, щоб не засмічувати весь комп'ютер.

```bash
python -m venv venv
```

Тепер його треба **активувати**:

- **Windows (PowerShell):**
  ```powershell
  venv\Scripts\activate
  ```
- **Windows (cmd):**
  ```cmd
  venv\Scripts\activate.bat
  ```
- **macOS / Linux:**
  ```bash
  source venv/bin/activate
  ```

Якщо все ок — на початку рядка в терміналі з'явиться `(venv)`. Це означає, що
середовище активне.

> Цей крок можна пропустити, але тоді бібліотеки встановляться глобально.
> Для навчання це не страшно, але звичка робити venv — хороша.

---

## Крок 3. Встанови бібліотеки

```bash
pip install -r requirements.txt
```

Ця команда прочитає файл `requirements.txt` і встановить усе одразу: pygame,
numpy, pandas, ursina.

> **Linux, ВАЖЛИВО:** для Pong, Connect 4 і GPS-інструмента обов'язково
> потрібен tkinter. Без нього ці ігри просто не запустяться (вилетять із
> помилкою `No module named 'tkinter'`). Встанови його:
> ```bash
> sudo apt install python3-tk
> ```
> На Windows і macOS tkinter уже вбудований — нічого робити не треба.

---

## Крок 4. Запусти меню

```bash
python main.py
```

Має відкритися повноекранне меню з написом **MAIN MENU** і трьома кнопками:

- **PROGRAMS** — список ігор.
- **GUIDE** — як грати в кожну гру.
- **QUIT** — вийти.

Якщо меню з'явилось — вітаю, все встановлено! 🎉

## Крок 5. Протестуй усе (чекліст)

Пройдись по списку й познач, що працює. Так ти одразу знайдеш, якщо десь
загубився ассет після перейменування папок.

**Меню:**
- [ ] Кнопки підсвічуються зеленим, коли наводиш мишку.
- [ ] Чути музику на фоні (якщо є звук на комп'ютері).
- [ ] Стрілки `<` `>` гортають сторінки списку ігор.
- [ ] Кнопка **BACK** повертає в головне меню.

**Ігри** (клікай кожну в PROGRAMS, перевіряй, що запускається і закривається):

| -------------- | ---------------------------------- | ------------------- |
| Puissance 4    | Мишка + лівий клік по колонці      | Закрити вікно       |
| Flappy Bird    | Пробіл — злетіти                   | Кнопка Exit / вікно |

## Якщо не працює

**`ModuleNotFoundError: No module named 'pygame'` (або numpy/pandas/ursina)**
Бібліотеки не встановились. Перевір, що venv активний (`(venv)` на початку
рядка), і повтори:
```bash
pip install -r requirements.txt
```

**`No module named 'tkinter'` (Linux)**
```bash
sudo apt install python3-tk
```

**`pygame.error: ... No such file or directory` (не знаходить картинку/звук)**
Це значить, що гра шукає ассет за старим шляхом. Запусти меню з **кореневої
папки проєкту** (там, де лежить `main.py`), а не зсередини папки гри.

**Меню відкрилось, але одразу чорний екран / нічого не видно**
Це повноекранний режим. Спробуй Alt+Tab або закрий вікно (Alt+F4 на Windows).
Переконайся, що файл `assets/Background.png` на місці.

**Гра запускається двічі з одного кліку**
Цього вже не має бути — у новій версії клік ловиться через подію. Якщо все ж
трапляється, скажи мені.

**`python: command not found`**
Спробуй `python3` замість `python` у всіх командах вище.
